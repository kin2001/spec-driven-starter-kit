# Third-party notices

Bundled dependencies are MIT licensed. Full original license text is retained in each exported skill directory. No upstream hooks, plugin configuration, or package-manager state is installed.

Superpowers includes all 15 skill siblings to keep internal skill references available (including writing-skills and diagnosing-superpowers). UI/UX Pro Max materializes canonical src scripts/data and retains its pristine upstream skill and references. Its upstream examples use CLAUDE_PLUGIN_ROOT; resolve the actual directory containing its SKILL.md and invoke Python with the absolute path to scripts/search.py instead. No plugin environment variable is required for the bundled search scripts. Ponytail exports its six skills only.
